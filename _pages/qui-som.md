Aquesta web l'hem feta **Adrià Autonell** i **Pere** per a la pràctica de *Static Site Generators* del mòdul d'Implantació d'aplicacions web (ASIX, 2n curs).

NetCore Systems no existeix: és l'empresa que ens hem inventat per donar sentit al contingut. El que sí que és real són les comandes i les explicacions, que són coses que hem fet servir a classe.

## Com està feta

| Què | Amb què |
|-----|---------|
| Generador de la web | [Jekyll](https://jekyllrb.com/) |
| Tema | minima, amb CSS i plantilles pròpies |
| Contingut | Markdown |
| Codi font | Git + GitHub |
| Publicació | GitHub Pages |
| Desplegament | GitHub Actions (automàtic a cada `git push`) |

## Qui ha fet què

- **Adrià:** configuració de Jekyll, estructura i plantilles, secció de Linux, primer article, GitHub Pages i GitHub Actions.
- **Pere:** seccions de Xarxes i Serveis, articles de DNS i SSH, imatges i proves.
